⚡ Les 4 Piliers des Solutions /boost

Pourquoi restreindre un projet à un seul agent de codage ? Orchestrez la complémentarité de vos agents IA préférés.

PILIER 01

Délégation de Tâches

Routez chaque tâche vers l'agent le plus qualifié : conception à Claude Code, algorithmique à Codex, vitesse à Grok, et planification globale à Antigravity.

PILIER 02

Revue Red Team Contradictoire

Éliminez les angles morts. Faites auditer le code d'un agent par un agent concurrent spécialisé en sécurité, failles d'injection et conditions de concurrence (--focus).

PILIER 03

Auto-Sauvetage Résilient

La commande rescue répare automatiquement un test cassé en mode écriture, tout en capturant un instantané git stash create (rollbackRef) pour annuler immédiatement en cas d'imprévu.

PILIER 04

Supervision en Direct

Tableau de bord unifié runs et suivi des logs en continu (status <job-id> --follow) avec PIDs système, durées de vie en direct et journal d'événements NDJSON.

❓ Foire Aux Questions (FAQ)

Tout ce qu'il faut savoir sur l'interconnexion entre Claude Code, Codex, Grok et Antigravity.

Comment fonctionne la passerelle entre Claude Code, Codex, Grok et Antigravity ?

Polyglot Agent Connectors fournit un pont unifié qui convertit les commandes slash et requêtes de délégation en invocations locales sécurisées. Chaque agent reçoit les diffs Git isolés dans un snapshot ou un worktree détaché, et renvoie un verdict typé conforme au schéma JSON.

Les identifiants et clés API sont-ils partagés entre agents ?

Non. La passerelle applique une politique stricte de Zero Credential Leak : aucun jeton n'est partagé ou inspecté. Chaque connecteur réutilise simplement la session locale authentifiée de son CLI hôte respectif.

Comment l'auto-rescue garantit-il l'absence de perte de données ?

Avant toute écriture sur le disque, le pont appelle git stash create pour capturer l'état exact du dépôt. Le SHA retourné (rollbackRef) est conservé dans le registre de travail, permettant d'annuler les modifications en une seule commande en cas d'anomalie.
